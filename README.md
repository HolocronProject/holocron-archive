# Holocron Archive Ver0.4.1

## 反映方法
1. ZIPを展開する
2. 展開したフォルダ内の中身を、既存の `P:\GitHub\holocron-archive` に上書きコピー
3. VS Codeで `P:\GitHub\holocron-archive` を開く
4. `index.html` を右クリック → Open with Live Server
5. 問題なければGitHub DesktopでCommit → Push
